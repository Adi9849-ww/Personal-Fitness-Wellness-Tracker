# Personal Fitness and Wellness Tracker

A desktop-based **Java application** designed to help users log, monitor, and analyze their daily physical activities, health metrics, and overall wellness goals. Built using strict **Object-Oriented Programming (OOP) principles**, this project offers a simple, efficient tool for personal health tracking.

## 🚀 Features

- **User Profile Management**: Setup and modify personal profiles including name, age, weight, and height.
- **Activity & Workout Logging**: Track diverse exercise routines, duration (in minutes), intensity, and individual dates.
- **Health Metrics Calculator**: Built-in automated calculation for Body Mass Index (BMI) and estimated daily calorie burn. 
- **Progress History**: Local data storage capability to view, track, and update complete exercise histories over time.

## 🛠️ Tech Stack & Prerequisites

- **Language**: Java (JDK 8 or higher required)
- **IDE**:IDLE(or)VS Code
- **Build/Run Environment**: Command Line Interface (CLI) / Terminal

## 📄 Project Overview
Objective:Help users track exercises, calculate health stats (like BMI and calories burned), and maintain logs.
Interface: Menu-driven console interface .
Core Concepts:Data Types, Scanner, Arithmetic Operators, Formatted Printing, Conditional Statements (if-else), Iteration (while loop),1D Array Traversal, Methods, Summation
